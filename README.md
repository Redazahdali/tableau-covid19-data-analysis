# Tableau — COVID-19 Data Analysis

Tableau data analysis and visualization project exploring COVID-19 cases, deaths, population and infection trends.

## Project Overview

This project uses Tableau to explore COVID-19 data through several analytical visualizations.

The analysis focuses on:
- COVID-19 cases and deaths
- Population data
- Infection levels and trends
- Death analysis by continent
- Geographic analysis
